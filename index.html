How sharing works

1 · Paste a link

Drop in the public play link from Spawn, GDevelop, Gear Zero, Unity, Godot, Playdrop, Ludo.ai, Tesana, Rosebud.ai or Refybe. We detect the platform for you.

2 · Or upload a build

Upload a single .html file or a .zip of a web export (it needs an index.html). It runs right here, stored in your browser.

3 · Publish on Git

Hit Publish on any of your games to get a ready-made package for your GitHub repo. Commit it and GitHub Pages shows your game to everyone.
